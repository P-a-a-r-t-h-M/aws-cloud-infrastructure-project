# AWS Cloud Infrastructure Design Project

## Project Overview

This project demonstrates the design, deployment, and cost estimation of a cloud infrastructure solution on Amazon Web Services (AWS).

The solution includes the creation of a Virtual Private Cloud (VPC), public and private subnets, route tables, internet connectivity, security groups, EC2 instances, and AWS cost estimation using the AWS Pricing Calculator.

The project was developed to apply cloud computing concepts, infrastructure design principles, networking fundamentals, and AWS service configuration.

## Setup Instructions

### Prerequisites

To recreate this project, you will need:

- AWS Academy Learner Lab or AWS Account
- AWS Pricing Calculator Access

### Core Implementation Steps

1. Create a Virtual Private Cloud (VPC).
2. Configure public and private subnets.
3. Create and attach an Internet Gateway.
4. Configure route tables and subnet associations.
5. Launch EC2 instances.
6. Configure Security Groups.
7. Test connectivity.
8. Estimate infrastructure costs using AWS Pricing Calculator.
